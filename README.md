# Buenos Aires 2026

Guia estático de 15 a 19 de outubro de 2026, com a mesma proposta de leitura do projeto Paris–Londres: abas, dias expansíveis, busca, checklist local, mapas e impressão.

Sem dependências e sem compilação. A página pública é `index.html`. Não publicar comprovantes, localizadores, documentos ou números de programas de fidelidade.

Validação: `node check.mjs`. Abrir `index.html` em um navegador para uso local; a publicação usa GitHub Pages, branch `main`, pasta raiz.

O checklist usa armazenamento local deste navegador, sem sincronização. As marcações não fazem reservas. Todas as opções não contratadas permanecem identificadas como propostas.

Pesquisa e planejamento: 28/09/2026. O teto de hotel é R$ 2.000 por noite; Uber/Cabify são a primeira opção de transporte aeroportuário, respeitando a capacidade de bagagem.
